   - **方块生成**: 随机生成、特殊方块生成、权重选择算法
   - **方块操作**: 旋转(顺逆时针)、移动(左右下)、形状获取
   - **碰撞检测**: 边界碰撞、方块间碰撞、详细碰撞信息
   - **高级功能**: 踢墙判定、幽灵位置计算、方块放置验证
   - **配置管理**: 动态配置更新、特殊方块开关

3. **碰撞检测工具 (src/utils/collision.ts)**：
   - **CollisionDetector类**: 专业的碰撞检测和移动验证
   - **移动检测**: canMove() 检查各方向移动可行性
   - **旋转检测**: canRotate() 检查旋转是否可行
   - **位置验证**: 安全位置检查、区域空白检测
   - **高级检测**: 方块重叠、周围空白、着陆检测
   - **工具函数**: 距离计算、边界检查、位置字符串转换

4. **完整测试套件 (test/blockSystemTest.ts)**：
   - **BlockSystemTest类**: 继承BaseTest，全面测试覆盖
   - **方块生成测试**: 基础方块、特殊方块、ID唯一性
   - **旋转测试**: 顺逆时针旋转、连续旋转循环、形状获取
   - **移动测试**: 三方向移动、位置计算、移动验证
   - **碰撞测试**: 左右下边界、方块间碰撞、移动可行性
   - **特殊功能测试**: 特殊方块创建、配置更新、定位功能

### 核心算法实现
- **旋转矩阵**: 4×4矩阵存储方块形状，支持4个旋转状态
- **踢墙判定**: 旋转时尝试5个偏移位置(-1,0), (1,0), (0,-1), (-2,0), (2,0)
- **碰撞检测**: 遍历方块形状矩阵，检查每个实心位置的边界和占用
- **幽灵位置**: 向下移动直到碰撞，回退一步得到投影位置
- **权重随机**: 计算总权重，随机选择，按权重分布返回方块类型

### 特殊功能支持
- **炸弹方块**: 单格特殊方块，爆炸半径1格
- **锁定方块**: 单格特殊方块，锁定时间3秒
- **特殊方块概率**: 默认10%，用户可配置
- **方块ID**: 唯一标识，格式 block_[counter]_[timestamp]
- **时间戳**: 方块创建时间，用于生命周期管理

- **分数计算**: 基础分数[100,300,500,800] + 特殊效果奖励 + 被炸方块10分
- **AI评估算法**: 分数 = 完成行×1000 - 高度×10 - 空洞×50 - 不平整×5
- **游戏板分析**: 列高度统计、空洞计算、表面不平整度评估

### 行消除分数系统
- **1行**: 100分 (Single)
- **2行**: 300分 (Double) 
- **3行**: 500分 (Triple)
- **4行**: 800分 (Tetris)
- **特殊效果**: 炸弹500分 + 被炸方块×10分，锁定破坏200分

### 特殊方块效果
- **炸弹方块**: 
  - 触发条件：行消除时包含炸弹方块
  - 效果范围：以炸弹为中心1格半径的十字区域
  - 奖励分数：500分基础 + 每个被炸方块10分
- **锁定方块**:
  - 锁定时间：3000ms (可配置)
  - 锁定状态：期间无法被行消除清除
  - 解锁机制：时间到期自动解锁，恢复普通方块
  - 破坏奖励：200分
