# React 贪吃蛇游戏

一个使用React、Vite和Canvas API开发的现代化贪吃蛇游戏。

## 🎮 功能特点

- 🎯 经典的贪吃蛇游戏玩法
- 🎨 现代化的UI设计，渐变背景和阴影效果
- 🏆 分数系统和最高分记录（本地存储）
- ⏸️ 暂停/继续功能
- 🔄 重新开始功能
- 🎯 自适应游戏速度（随着得分增加而加快）
- 📱 响应式设计，支持移动设备
- ⌨️ 支持方向键和WASD键控制
- ⚛️ 使用React Hooks和函数式组件

## 🚀 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

## 🎯 游戏控制

### 键盘控制
- **方向键** 或 **WASD键**：控制蛇的移动方向
  - ↑ 或 W：向上移动
  - ↓ 或 S：向下移动
  - ← 或 A：向左移动
  - → 或 D：向右移动

### 按钮控制
- **开始游戏**：开始新游戏
- **暂停**：暂停/继续当前游戏
- **重新开始**：重置游戏状态

## 🎮 游戏规则

1. 使用方向键或WASD键控制蛇的移动
2. 吃到红色食物可以增加分数（每个食物10分）和蛇的长度
3. 撞到墙壁或自己的身体会游戏结束
4. 游戏速度会随着得分增加而逐渐加快
5. 最高分会保存在本地存储中

## 🛠️ 技术栈

- **React 18**：用户界面框架
- **Vite**：构建工具和开发服务器
- **Canvas API**：游戏渲染
- **CSS3**：现代化样式设计
- **LocalStorage**：数据持久化
- **React Hooks**：状态管理和副作用

## 🎨 组件设计

### SnakeGame组件
主要的游戏组件，包含以下功能：

- **状态管理**：使用useState管理游戏状态
- **游戏循环**：使用useEffect和setTimeout实现
- **键盘事件**：使用useEffect监听键盘输入
- **Canvas渲染**：使用useRef和useEffect进行绘制
- **碰撞检测**：检查墙壁和自身碰撞
- **分数系统**：实时更新分数和最高分

### 核心Hooks使用
- `useState`：管理游戏状态（蛇、食物、分数等）
- `useEffect`：处理副作用（游戏循环、键盘事件、绘制）
- `useCallback`：优化性能，避免不必要的重新渲染
- `useRef`：引用Canvas元素和游戏循环定时器

## 🎯 游戏逻辑

1. **初始化**：设置初始蛇位置、食物位置和游戏状态
2. **游戏循环**：定期移动蛇并检查碰撞
3. **输入处理**：监听键盘事件并更新移动方向
4. **碰撞检测**：检查墙壁碰撞和自身碰撞
5. **食物系统**：生成随机食物位置和分数计算
6. **状态更新**：实时更新游戏状态和UI

## 🎨 样式设计

- **渐变背景**：使用CSS渐变创建现代化背景
- **阴影效果**：为按钮和卡片添加阴影
- **圆角设计**：现代化的圆角界面
- **响应式布局**：支持移动设备
- **动画效果**：按钮悬停和点击动画
